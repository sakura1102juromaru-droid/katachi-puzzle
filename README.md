# かたちを しろう（まる・さんかく・しかくの 型はめアプリ）

特別支援学校小学部1年生 算数「形を知ろう」単元に向けた、丸・三角・四角の型はめWebアプリケーションです。  
直感的な操作、温かみのあるビジュアル、スモールステップ設計、手厚いマルチモーダル・フィードバック（音声合成・効果音・花丸演出）により、児童が主体的に楽しく学べるよう配慮されています。

---

## 🌟 特徴と教育的配慮

1. **完全スタンドアロン・オフライン動作**
   - 外部ライブラリや画像・音声ファイルへの外部通信が一切不要です。
   - `index.html` をダブルクリックするだけで、教室のオフラインPC、電子黒板、iPad、Chromebookのブラウザですぐに起動します。

2. **スモールステップ（4段階の学習ステップ）**
   - **ステップ 1：まる（1つ）**：まずは「丸」を枠に入れる基本操作と「できた！」という達成感を味わいます。
   - **ステップ 2：ふたつ（〇と△）**：2つの形の弁別を学びます。
   - **ステップ 3：みっつ（〇・△・□）**：単元の基本目標である3種類の形を弁別します。
   - **ステップ 4：たくさん（6つ）**：複数のピースをそれぞれの枠に分類する応用問題です。

3. **色と形の弁別支援（難易度調整）**
   - **いろつき（かんたん）**：枠にも図形と同じ色がついており、「色」を手がかりに型はめができます。
   - **かげ・グレー（チャレンジ）**：枠がグレー（シルエット）になり、純粋に「形の幾何学的特徴」に着目して合わせます。

4. **多様な運動・認知特性に寄り添う操作設計**
   - **ドラッグ＆ドロップ**：タッチ操作・マウス・電子黒板ペンに対応。
   - **広い吸着判定（スナップ機能）**：指先の微細運動が苦手な児童でも、枠の近くに持っていくだけで「カチッ」と気持ちよく吸い付きます。
   - **タップで選ぶモード**：長押しやドラッグの保持が難しい児童向け。「形をタップ」→「枠をタップ」で移動できます。
   - **かんたんタップ（自動移動モード）**：形をタップするだけで正しい枠にスーッと飛んで入るアシストモードです。

5. **マルチモーダル＆ポジティブなフィードバック**
   - **Web Speech API（日本語読み上げ）**：形を触った時・入った時に「まる！」「さんかく！」「しかく！」「ぴったり！」と温かい声で発話します。
   - **Web Audio API（効果音）**：心地よいチャイム音やキラキラ音。
   - **否定的な表現の排除**：間違えた枠に置いても不快なブザー音や「×」印は出ず、「ぽよん」と優しく跳ねて元の位置に戻ります。
   - **大きな花丸と紙吹雪**：全部入ると画面いっぱいの「はなまる（たいへんよくできました！）」とファンファーレで達成感を高めます。

## 💻 使い方・起動方法

### PC / 電子黒板の場合
1. フォルダ内の `index.html` をダブルクリック（または右クリック → お好みのブラウザで開く）。
2. 画面右上の **「ぜんめん」ボタン** を押すと、フルスクリーン表示になり、児童の誤操作やツールバーのタップを防げます。

### iPad / タブレットの場合
- AirDropやGoogleドライブ等でiPadに送り、SafariまたはChromeで開きます。
- 「ホーム画面に追加」をすると、全画面アプリのように起動できます。

## ⚙️ せってい（指導者用メニュー）

画面右上の **「⚙️ せってい」** ボタンから、児童の実態に合わせて以下をいつでも調整できます：

| 項目 | 選択肢 | 指導上の狙い・配慮 |
| :--- | :--- | :--- |
| **がくしゅう すてっぷ** | 1〜4 | 児童の実態や授業の進度に応じたスモールステップ |
| **わくの ヒント** | いろつき / かげ（グレー） | 色の手がかりを外して「形」だけの弁別へ移行する支援 |
| **そうさの ほうほう** | ドラッグ / タップ / かんたん自動 | 児童の手指の巧緻性や端末操作の習熟度に応じた変更 |
| **かたちのおかお** | ON / OFF | 形に愛着を持ちやすくするにっこり顔の表示切替 |
| **こえのよみあげ** | ON / OFF | 形の名称（「まる」「さんかく」「しかく」）の音声支援 |
| **こうかおん** | ON / OFF | 音刺激に過敏な児童がいる場合はOFFに設定可能 |
| **なまえの ひょうじ** | ON / OFF | ひらがな文字（まる・さんかく・しかく）の表示切替 |

## 🏫 指導案での展開例（本時の流れ）

1. **導入（5分）**
   - 電子黒板でステップ1（丸）を提示し、指導者が「まる、あったね」「ここに入るかな？」とモデル提示。
   - 児童が前に出て電子黒板をタッチ・ドラッグして「ぴったり！」を体験。
2. **展開（20分）**
   - 児童各自のタブレット端末、または個別学習で実施。
   - 実態に合わせて、ステップ1（丸のみ）からステップ2（丸と三角）、ステップ3（3種）へ段階的に進める。
   - 形の名称を一緒に声に出しながら「まる」「さんかく」「しかく」を意識させる。
3. **まとめ・振り返り（5分）**
   - 「みんな、まる・さんかく・しかくの型はめ、たくさん花丸をもらえたね！」と称賛し、教室の中にある身近な丸・三角・四角（時計、黒板、三角定規など）を見つける活動へ繋げる。
